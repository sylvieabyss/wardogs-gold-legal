# WARDOGS Gold Privacy Policy

**Effective date:** October 2, 2026  
**Made and maintained by Sylvie Abyss**

This Privacy Policy explains how WARDOGS Gold ("WARDOGS Gold", "the Bot", or "the Service") processes information when you use it.

WARDOGS Gold is designed to collect and retain as little user information as reasonably necessary to provide its features.

## 1. Operator

WARDOGS Gold is made and maintained by **Sylvie Abyss**.

Privacy questions, data-access requests, and deletion requests may be submitted through the official WARDOGS Gold support or contact channel listed on the Bot's public project or application page.

## 2. Scope

This Policy covers information processed by WARDOGS Gold itself.

Discord, WispByte, GitHub, MetaForge, WardogStats, and other third-party services have their own privacy practices and policies.

## 3. Information WARDOGS Gold Processes

The exact information processed depends on which features you use.

### Discord Interaction Data

When you use a slash command or otherwise directly interact with the Bot, Discord provides information needed to process that interaction.

This may include:

- Discord user ID
- Discord server ID
- Discord channel ID
- Command name
- Command options or values you submit
- Basic interaction metadata supplied by Discord

Most interaction data is processed transiently and is not stored unless a feature requires persistence.

WARDOGS Gold does not use normal Discord message content to provide its core functionality.

### Discord Server ID

Stored when a server configures WARDOGS Gold.

Used to associate settings and alerts with the correct Discord server.

### Discord Channel ID

Stored when a server configures an automatic gold-price update channel.

Used to determine where configured updates should be posted.

### Discord Role ID

Stored only when a server configures a role for price-update mentions.

Used only for that notification feature.

### Discord User ID

Stored when a user creates a personal price alert or when another persistent user-specific feature requires it.

Used to associate the feature with the correct Discord account.

### Alert Data

For active or recently triggered alerts, the Bot may store:

- Alert ID
- Discord user ID
- Discord server ID
- Alert threshold
- Alert direction
- Delivery state
- Retry state
- Creation time
- Trigger time

This information is required to operate price alerts and prevent repeated delivery.

### Server Configuration

The Bot may store:

- Discord server ID
- Configured announcement channel
- Optional mention role
- Whether automatic announcements are enabled
- The last announced quote or price

This allows server configuration to survive Bot restarts and helps prevent duplicate announcements.

### Public Gold Price Data

WARDOGS Gold stores public gold-price information obtained from external community sources.

This may include:

- Quote date
- Gold price
- Data source
- Source-confirmation state
- Price revisions
- Fetch timestamps

This is game-market information and is not intended to identify individual users.

### Operational Logs

WARDOGS Gold creates operational logs for reliability, debugging, abuse prevention, and security.

Logs may contain:

- Discord server IDs
- Discord channel IDs
- Error messages
- Provider failures
- Service events
- Timestamps

The Bot is designed not to intentionally write Discord bot tokens, user passwords, or other authentication credentials to its application logs.

## 4. Information WARDOGS Gold Does Not Intentionally Collect or Retain

WARDOGS Gold does not require or intentionally retain:

- Normal Discord message content
- Discord message history
- Email addresses obtained from Discord
- Phone numbers
- Real names
- Account passwords
- Steam credentials
- WARDOGS account credentials
- Payment card information
- Precise geolocation
- Advertising profiles
- Browsing histories
- User relationship profiles
- Sensitive personal information for targeted profiling

WARDOGS Gold does not use Discord's Message Content privileged intent for its normal operation.

WARDOGS Gold does not use stored Discord identifiers for targeted advertising.

WARDOGS Gold does not sell personal information.

## 5. How Information Is Used

Information is processed only when reasonably necessary to:

- Respond to Bot commands
- Provide requested features
- Store server configuration
- Send gold-price updates
- Create and deliver price alerts
- Prevent duplicate announcements
- Maintain public price history
- Detect stale or conflicting source data
- Diagnose failures
- Prevent abuse
- Maintain security and reliability
- Comply with applicable legal obligations

Discord API data is not used for unrelated profiling, advertising, or eligibility decisions.

## 6. Lawful Bases Where GDPR or UK GDPR Applies

Where the EU GDPR or UK GDPR applies, WARDOGS Gold processes personal data only when a lawful basis applies.

Depending on the feature and circumstances, those bases may include:

- **Legitimate interests:** operating, securing, maintaining, and troubleshooting WARDOGS Gold, while limiting collection to what is reasonably necessary.
- **Performance of a contract or steps requested by the user:** providing a feature the user has requested, such as creating or delivering a price alert, where this basis applies under applicable law.
- **Legal obligation:** retaining or disclosing information when required by applicable law.

WARDOGS Gold does not rely on consent for routine Bot operation unless consent is specifically requested for a particular feature.

## 7. Discord Profile Activity

WARDOGS Gold may display the current or last confirmed WARDOGS gold price through its own Discord profile activity or status.

This does not require the Bot to monitor individual users' Discord presence.

## 8. Sharing and Service Providers

WARDOGS Gold does not sell personal information.

Information may be processed by or disclosed to third parties only when reasonably necessary to operate the Service, comply with law, or protect the Service.

### Discord

Discord provides the platform and API used by WARDOGS Gold.

Discord processes information independently under its own terms and privacy policy.

### Gold Price Data Providers

WARDOGS Gold may retrieve public market information from services such as MetaForge and WardogStats.

WARDOGS Gold does not intentionally send your Discord user ID, server ID, alert settings, or other Discord account information to these providers as part of normal price retrieval.

### Legal and Security Disclosures

Information may be disclosed when reasonably necessary to:

- Comply with applicable law
- Respond to a valid legal request

### Legal-Page Hosting

If these policies are hosted through a service such as GitHub Pages, that provider may independently process connection and usage information when you visit those pages.

## 9. Data Retention

WARDOGS Gold keeps personal information only for as long as reasonably necessary for the feature or operational purpose for which it was collected.

### Active Alerts

Active alert information is retained until the alert:

- Fires
- Is deleted by the user
- Is removed because the relevant server is no longer available to the Bot
- Is otherwise no longer needed to provide the feature

### Triggered Alerts

Triggered alert records may be retained for up to **30 days** for delivery reliability, troubleshooting, and duplicate-prevention purposes before cleanup.

### Server Configuration

Server configuration is retained while needed to operate WARDOGS Gold in that server.

WARDOGS Gold is designed to remove server-specific configuration and alerts when the Bot is removed from that Discord server.

### Operational Logs

WARDOGS Gold's own rotating application logs are generally retained for up to approximately **14 days**, subject to operational needs.

A hosting provider may maintain separate infrastructure logs under its own retention practices.

### Public Price History

Public WARDOGS price history may be retained indefinitely because it is not intended to identify individual users.

### Legal or Security Exceptions

Information may be retained longer where reasonably necessary for security investigations, dispute resolution, legal obligations, or the establishment, exercise, or defense of legal claims.

## 10. Data Deletion

Users may delete active alerts through the Bot where the relevant command is available.

Server administrators may disable announcements, change stored configuration, or remove the Bot from their server.

You may also request deletion of personal information associated with your Discord account through the official WARDOGS Gold support or contact channel listed on the Bot's public project or application page.

A request may require reasonable verification that you control the relevant Discord account or server.

WARDOGS Gold will delete Discord API data when it is no longer necessary for the Bot's stated functionality, when deletion is required by applicable law, when Discord requires deletion, or when a valid user deletion request applies, subject to lawful exceptions.

Public gold-price history is not treated as user account data.

Price-alert triggering is based only on the threshold selected by the user and the current confirmed game-market price.
